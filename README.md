# Информационная безопасность — лабораторная №4
## Запуск

Нужен Python 3.10 или новее; внешние библиотеки для симулятора не требуются.

```powershell
cd "Лабораторная работа 4/проект_уз_испдн"
python программы/главный_симулятор.py все
python программы/главный_симулятор.py тесты
```

Интерактивные команды: `все`, `система КД`, `сценарий 1`, `сценарий импорт КД`, `тесты`, `выход`.

Проверки находятся в `тесты/проверки.py`, вспомогательные функции оформления — в `программы/документы.py`. Исходные снимки хранятся в `данные/исходное_состояние.py` и `данные/исходное_оборудование.py`.

В `отчёты` отдельно сохраняются шесть сценариев, таблица тестов TXT/JSON, сравнение состояний и машиночитаемый результат. В `документы` сохраняются готовые DOCX-акты и нормативные источники. Эти дополнительные файлы сохранены для удобства проверки и сопровождения проекта.

61 тест проходит. Рабочие данные намеренно содержат три дефекта; аудит даёт 83,3/100. Контрольная копия без дефектов — 97,6/100; замечание о статусе учебных СЗИ остаётся.

Матрица сверена со слайдом 5 лекции №5 Маршева Н.А. «Методические рекомендации ФСТЭК. Уровни защищенности ИСПДн». Ровно 100000 субъектов — явно обозначенное учебное допущение; в лекции только интервалы «менее» и «более». Схемы ОТСС/ВТСС в этой лекции нет.
